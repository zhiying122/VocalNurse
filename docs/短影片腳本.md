## 螢幕錄製注意事項（OBS 設定）

### 錄製前準備
1. **解析度**：1920 × 1080（Full HD）
2. **瀏覽器**：Chrome，放大到 110%（讓文字更清楚）
3. **提前準備好測試資料**：先新增 2-3 位病患，確保有紀錄可以展示
4. **提前跑一次 SOAP 生成**：讓 Ollama 模型載入記憶體，避免 Demo 時等太久
5. **關閉所有通知**：避免錄製時彈出 Line、Email 等通知

### OBS 設定
1. 下載 [OBS Studio](https://obsproject.com/)
2. 來源 → 新增「視窗擷取」→ 選擇 Chrome 視窗
3. 輸出設定 → 錄影格式 MP4 → 品質「高品質」
4. 開始錄製 → 操作系統 → 停止錄製

### 錄製技巧
- 滑鼠移動要慢，讓觀眾看清楚你在點什麼
- 每個步驟之間停頓 1-2 秒
- 如果 SOAP 生成太慢（超過 10 秒），可以用剪輯加速或跳接
- 錄多次，選最流暢的一次

## 剪輯建議（剪映 / CapCut）

### 片頭製作
1. 開啟剪映 → 新建專案 → 16:9 橫式
2. 加入純色背景（#1e3a5f 深藍）
3. 加入文字「VoiceNursy 護理聲助手」→ 動畫選「淡入」
4. 加入 Logo 圖片 → 動畫選「縮放進入」
5. 時長 10 秒

### 字幕
- 全程加上繁體中文字幕（剪映有自動字幕功能）
- 字幕字體：黑體或圓體，白色，帶黑色描邊
- 重點數字用黃色或橘色標示

### 配樂
- 剪映內建免費配樂 → 搜尋「corporate」「inspiring」「medical」
- 音量調到 20-30%，不要蓋過旁白

### 轉場
- 片段之間用「淡入淡出」或「滑動」轉場
- 不要用太花俏的轉場效果

---

## 旁白錄製建議

- 用手機錄音即可（找安靜的房間）
- 語速適中，不要太快
- 每段旁白錄完後聽一次，確認清楚
- 如果不想自己錄，可以用剪映的「文字轉語音」功能（選台灣口音）

## Demo 前的暖機步驟（重要！）

決賽當天或錄影前，務必先做以下步驟，避免 Demo 時 Ollama 回應太慢：

```bash
# 1. 確認 Ollama 在運行（系統列應該有圖示）

# 2. 啟動後端
cd brain
python -m uvicorn api:app --reload --port 8001

# 3. 啟動前端
cd safety-ui
python -m http.server 3000

# 4. 暖機：先跑一次 SOAP 生成，讓模型載入記憶體
#    在瀏覽器登入 → 選病患 → 手動輸入「病患主訴頭痛」→ 生成 SOAP
#    第一次會比較慢（30-60 秒），之後就會快很多（5-10 秒）

# 5. 確認暖機成功後，再開始錄影或 Demo
```

# VoiceNursy 競賽海報製作指南（A1 尺寸）

## 海報規格

- **尺寸**：A1（594mm × 841mm），直式
- **解析度**：300 DPI（印刷品質）
- **檔案格式**：PDF 或 PNG

---

## 推薦工具

### 方案 1：Canva（最推薦，免費）
1. 到 [canva.com](https://www.canva.com) 註冊免費帳號
2. 點「建立設計」→ 自訂尺寸 → 輸入 594 × 841 mm
3. 搜尋模板關鍵字：「research poster」「academic poster」「medical poster」
4. 選一個乾淨的模板，替換成以下內容
5. 完成後下載 PDF（列印品質）

### 方案 2：PowerPoint
1. 開啟 PowerPoint → 設計 → 投影片大小 → 自訂 → 59.4cm × 84.1cm
2. 自己排版（比較費時但彈性大）

### 方案 3：AI 生成背景圖
1. 到 [ideogram.ai](https://ideogram.ai) 或 [Leonardo.ai](https://leonardo.ai)
2. 輸入 prompt：`Medical technology poster background, soft blue and white gradient, hospital nursing theme, clean modern design, no text`
3. 下載背景圖，再用 Canva 疊上文字內容

```

語音驅動的智慧護理紀錄系統 — 用科技守護每一份照護的溫暖

團隊名稱：（你們的團隊名）
指導老師：（老師姓名）
成員：（成員姓名）
學校：（學校名稱）

SDG 3 良好健康與福祉 ｜ SDG 8 良好工作 ｜ SDG 9 創新
```

**設計建議**：深藍色背景（#1e3a5f），白色文字，左上角放 Logo

---

### 第二區：問題與動機（佔 15%）

**標題**：💝 護理師的困境

**內容**：
```
「每天下班後，我還要花兩個小時補寫護理紀錄。
 回到家，孩子已經睡了。」

• 台灣 17 萬名護理師
• 每人每天花 2-3 小時手寫病歷
• 佔工作時間 25-35%
• 壓縮直接照護病患的時間
```

**設計建議**：暖色背景（淡橘 #fef6ee），放一張護理師忙碌的示意圖

---

### 第三區：解決方案（佔 25%）

**標題**：🎯 VoiceNursy 怎麼解決？

**放系統流程圖**（6 個步驟，用箭頭連接）：
```
🎙️ 語音輸入 → 🔊 語音辨識 → 🧹 文字前處理 → 🧠 SOAP 生成 → 🛡️ 安全防呆 → 📊 視覺化輸出
(30 秒)      (Whisper)    (藥名標準化)   (Llama 3.2)   (2 秒攔截)    (交班報告)
```

**放 4 張系統截圖**（2×2 排列）：
1. 巡房模式（語音錄音畫面）
2. SOAP 卡片（生成結果）
3. 藥物安全警示（紅色彈窗）
4. 交班儀表板（統計摘要）

**設計建議**：白色背景，截圖加圓角和陰影

## Canva 操作步驟

1. 開啟 Canva → 建立設計 → 自訂 594 × 841 mm
2. 選一個學術海報模板
3. 把背景改成 #f5f7fa
4. 標題區用 #1e3a5f 深藍色塊
5. 依照上面 6 個區塊的順序填入內容
6. 插入系統截圖（從瀏覽器截取 4 張畫面）
7. 下載 → PDF 列印品質 → 送印 A1

## AI 生成海報背景的 Prompt

如果想用 AI 生成背景圖，可以用以下 prompt：

**Ideogram / Midjourney / Leonardo.ai：**
```
A clean, modern medical technology poster background. 
Soft gradient from deep navy blue (#1e3a5f) to white. 
Subtle medical icons (stethoscope, heartbeat line, hospital cross) 
as watermark patterns. Minimalist, professional, warm feeling. 
No text. High resolution, print quality, A1 poster size.
```

**DALL-E / ChatGPT Image：**
```
設計一張醫療科技海報的背景圖。
深藍色到白色的漸層，帶有淡淡的醫療圖示（聽診器、心跳線、醫院十字）作為浮水印。
風格簡潔、專業、溫暖。不要任何文字。高解析度，適合 A1 海報印刷。
```

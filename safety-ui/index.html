🔊 語音辨識層

模型OpenAI Whisper base（本地）
輸入格式WebM → ffmpeg 轉 16kHz WAV
語言支援中文 / 英文 / 台語混合
優化手段醫療術語 initial_prompt 注入 50+ 關鍵詞
部署方式本地 CPU，不需 GPU，不需網路

🧠 AI 推論層

主模型Llama 3.1 8B（Ollama 本地）
備援模型Gemini 2.0 Flash / GPT-4o
Prompt 策略角色扮演 + SOAP 分類規則 + JSON Schema 約束
前處理藥名標準化（30+ 映射）+ 縮寫統一（18 種）
隱私保護PII 遮罩（身分證/電話/姓名/Email）

🛡️ 防呆引擎

劑量檢查8 種常用藥品最大單次/每日劑量閾值
過敏原直接匹配 + NSAIDs 類別 + Penicillin 交叉過敏
生命徵象BP / HR / SpO2 / BT / RR 六項警戒值
觸發方式全螢幕紅色閃爍 + 提示音 + 強制確認
稽核記錄所有警示觸發與處置選擇均記錄

🏗️ 系統架構

後端Python FastAPI（非同步高效能）
前端原生 HTML/CSS/JS（零框架依賴）
圖表Chart.js（疼痛趨勢折線圖）
離線支援IndexedDB 本地暫存 + 網路恢復自動同步
認證PBKDF2-SHA256 密碼雜湊 + JWT Token

與直接使用 ChatGPT 的差異

❌ 直接用 ChatGPT

  • 病歷資料上傳雲端，違反個資法
  • 無法辨識台語和醫療口語
  • 沒有劑量防呆機制
  • 沒有過敏原交叉檢查
  • 輸出格式不穩定
  • 需要網路，醫院 WiFi 不穩就掛

✅ VoiceNursy

  • 全程本地運行，資料不出院
  • 醫療術語 Prompt 優化 + 校正字典
  • 即時劑量閾值比對，2 秒內攔截
  • Penicillin/NSAIDs 交叉過敏偵測
  • Pydantic Schema 強制 JSON 結構
  • IndexedDB 離線暫存，斷網照用
